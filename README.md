# Heart-Disease-Risk-EDA
Exploratory Data Analysis of Heart Disease Risk using Python, Pandas, NumPy, Matplotlib and Seaborn. Includes data understanding, preprocessing, statistical analysis, visualizations and key health-related insights.


## Exploratory Data Analysis of Heart Disease Risk

This project performs **Exploratory Data Analysis (EDA)** on a Heart Disease Risk dataset containing **9,000 patient records and 26 variables**.

The analysis explores demographic, clinical, lifestyle, and health-related factors associated with heart disease.

##  Project Objective

The main objective of this project is to:

* Understand the structure and characteristics of the dataset.
* Perform data cleaning and preprocessing.
* Analyze important health and lifestyle variables.
* Identify patterns and relationships related to heart disease.
* Visualize the data using different statistical plots.
* Generate meaningful insights from the analysis.

##  Dataset

The dataset contains **9,000 rows and 26 columns**.

Important variables include:

* Age
* Sex
* Resting Systolic Blood Pressure
* Resting Diastolic Blood Pressure
* Total Cholesterol
* HDL
* LDL
* Triglycerides
* Fasting Blood Sugar
* HbA1c
* Family History
* Smoking Status
* Alcohol Units per Week
* Exercise Minutes per Week
* Sleep Hours
* Stress Score
* Daily Steps
* Diet Quality Score
* Heart Disease Status

The target variable used for analysis is:

**`has_heart_disease`**

* Physical activity
* Sleep duration
* Stress level
* Diet quality
* Family history

##  Key Insights

Some important observations from the analysis include:

* Sleep duration is relatively similar between patients with and without heart disease, although the average is slightly lower among patients with heart disease.
* Patients without heart disease show a higher average diet-quality score than patients with heart disease.
* Lifestyle and health-related variables provide useful patterns for understanding differences between patients with and without heart disease.

##  Important Note

This project is an **EDA project**, so the observed relationships should not be interpreted as proof of causation.

The analysis identifies patterns and associations in the available dataset.
